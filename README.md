# RINSED: RUN AJ RUN

Mobile (touch, landscape) Three.js r128 chase-runner. Play: https://mono667.github.io/aj-race/

AJ flees a pack of six girls through three Thunder Bay neighbourhoods to his SAFE SPACE.
Each tag steals a heart; lose them all and AJ goes LOVESTRUCK. Power-ups: energy drink, SCOOTER, FANCY SHOES.

- WESTFORT: Neebing Ave (Westfort Playfield) → Frederica St W (village shops, fire hall) → Kam River trail
- FORT WILLIAM: May St (City Hall) → Victoria Ave E (1912 stone bank blocks) → Simpson St (rail yards, grain elevators) → James St Swing Bridge
- PORT ARTHUR (winter): High St / Hillcrest Park lookout → Red River Rd → Bay St Finnish district → Cumberland St (1913 terra-cotta tower, hotel) → Water St / Marina Park (Spirit Garden, lighthouse)

Landmarks are stylized props with generic names. `?seed=N` fixes obstacle/pickup layout.
Tests: `cd test && npm i playwright && node test.js` (serve the folder on :8766).
